# Lab_05 - DBMS ASSIGNMENT_03

## Program Specifications

* **Program_01**
  * **Problem Statement:** Write a query to display the first_name, last_name and salary for all employees whose salary is not in the range $10,000 through $15,000.

* **Program_02**
  * **Problem Statement:** Write a query to display the first_name, last_name and department ID for all employees in departments 30 or 100 in ascending order.

* **Program_03**
  * **Problem Statement:** Write a query to display the first_name, last_name and salary for all employees whose salary is not in the range $10,000 through $15,000 and are in department 30 or 100.

* **Program_04**
  * **Problem Statement:** Write a query to display the first_name, last_name and hire date for all employees who were hired in 1987.

* **Program_05**
  * **Problem Statement:** Write a query to display the first_name of all employees who have both "b" and "c" in their first name.

* **Program_06**
  * **Problem Statement:** Write a query to display the last_name, job_id and salary for all employees whose job is that of a Programmer or a Shipping Clerk, and whose salary is not equal to $4,500, $10,000, or $15,000.

## Lab Overview

* **Approach:** Wrote the required SQL queries, executed them in MySQL Workbench, and verified the output.
* **Time & Space Complexity:** Not applicable.
* **Sample Input/Output:** Queries and outputs are given in the respective program files.
* **Screenshots:** All corresponding output screenshots are available inside the Output folder.

## Learning Outcomes
Learned to filter employee records using the WHERE clause and operators like BETWEEN, IN, NOT IN, and LIKE. Also practiced pattern matching, date-based filtering, displaying distinct values, and performing calculations using SQL expressions.
