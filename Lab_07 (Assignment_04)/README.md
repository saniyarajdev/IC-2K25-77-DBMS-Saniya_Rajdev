# Lab_07 - DBMS ASSIGNMENT_04

## Program Specifications

* **Program_01**
  * **Problem Statement:** Write a query to list the number of jobs available in the employees table.

* **Program_02**
  * **Problem Statement:** Write a query to get the total salaries payable to employees.

* **Program_03**
  * **Problem Statement:** Write a query to get the minimum salary from employees table.

* **Program_04**
  * **Problem Statement:** Write a query to get the maximum salary of an employee working as a Programmer.

* **Program_05**
  * **Problem Statement:** Write a query to get the average salary and number of employees working the department 90.

* **Program_06**
  * **Problem Statement:** Write a query to get the highest, lowest, sum, and average salary of all employees.

* **Program_07**
  * **Problem Statement:** Write a query to get the number of employees with the same job.
 
## Lab Overview

* **Approach:** Wrote the required SQL queries, executed them in MySQL Workbench, and verified the output.
* **Time & Space Complexity:** Not applicable.
* **Sample Input/Output:** Queries and outputs are given in the respective program files.
* **Screenshots:** All corresponding output screenshots are available inside the Output folder.

## Learning Outcomes
Learned to use aggregate functions such as COUNT, SUM, MIN, MAX, and AVG to summarize employee data. Also practiced using GROUP BY to group records and HAVING to filter grouped results based on aggregate conditions.
