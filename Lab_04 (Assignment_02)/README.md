# Lab_04 - DBMS ASSIGNMENT_02

## Program Specifications

* **Program_11**
  * **Problem Statement:** Write a query to get all first name from employees table in upper case.

* **Program_12**
  * **Problem Statement:** Write a query to get the first 3 characters of first name from employees table.

* **Program_13**
  * **Problem Statement:** Write a query to calculate 171*214+625.

* **Program_14**
  * **Problem Statement:** Write a query to get the names of all the employees from employees table.

* **Program_15**
  * **Problem Statement:** Write a query to get first name from employees table after removing white spaces from both sides.

* **Program_16**
  * **Problem Statement:** Write a query to get the length of the employee names (first_name, last_name) from employees table.

* **Program_17**
  * **Problem Statement:** Write a query to check if the first_name fields of the employees table contains numbers.

* **Program_18**
  * **Problem Statement:** Write a query to select first 10 records from a table.

* **Program_19**
  * **Problem Statement:** Write a query to get monthly salary (round 2 decimal places) of each and every employee.

## Lab Overview

* **Approach:** Wrote the required SQL queries, executed them in MySQL Workbench, and verified the output.
* **Time & Space Complexity:** Not applicable.
* **Sample Input/Output:** Queries and outputs are given in the respective program files.
* **Screenshots:** All corresponding output screenshots are available inside the Output folder.
  
## Learning Outcomes
Learned how to pull specific columns out of a table using SELECT queries. Also practiced basic operations like sorting names alphabetically using ORDER BY, changing names to capital letters using UPPER, and calculating mathematical totals like SUM and AVG.
