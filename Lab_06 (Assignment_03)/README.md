# Lab_06 - DBMS ASSIGNMENT_03

## Program Specifications

* **Program_07**
  * **Problem Statement:** Write a query to display the last names of employees whose names have exactly 6 characters.

* **Program_08**
  * **Problem Statement:** Write a query to display the last names of employees having 'e' as the third character.

* **Program_09**
  * **Problem Statement:** Write a query to display the jobs/designations available in the employees table.

* **Program_10**
  * **Problem Statement:** Write a query to display the first_name, last_name, salary and PF (15% of salary) of all the employees.

* **Program_11**
  * **Problem Statement:** Write a query to select all record from employees where last name in 'BLAKE', 'SCOTT', 'KING', 'FORD'.

## Lab Overview 

* **Approach:** Wrote the required SQL queries, executed them in MySQL Workbench, and verified the output.
* **Time & Space Complexity:** Not applicable.
* **Sample Input/Output:** Queries and outputs are given in the respective program files.
* **Screenshots:** All corresponding output screenshots are available inside the Output folder.

## Learning Outcomes
Learned to filter employee records using the WHERE clause and operators like BETWEEN, IN, NOT IN, and LIKE. Also practiced pattern matching, date-based filtering, displaying distinct values, and performing calculations using SQL expressions.
