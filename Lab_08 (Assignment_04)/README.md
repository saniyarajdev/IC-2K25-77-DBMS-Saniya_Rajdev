# Lab_08 - DBMS ASSIGNMENT_04

## Program Specifications

* **Program_08**
  * **Problem Statement:** Write a query to get the difference between the highest and lowest salaries.

* **Program_09**
  * **Problem Statement:** Write a query to find the manager ID and the salary of the lowest-paid employee for that manager.

* **Program_10**
  * **Problem Statement:** Write a query to get the department ID and the total salary payable in each department.

* **Program_11**
  * **Problem Statement:** Write a query to get the average salary for each job ID excluding programmer.

* **Program_12**
  * **Problem Statement:** Write a query to get the total salary, maximum, minimum, and average salary of all jobs for department 90 only.

* **Program_13**
  * **Problem Statement:** Write a query to get the job ID and maximum salary of the employees where maximum salary is greater than or equal to $4,000.

* **Program_14**
  * **Problem Statement:** Write a query to get the average salary for all departments employing more than 10 employees.
 
## Lab Overview 

* **Approach:** Wrote the required SQL queries, executed them in MySQL Workbench, and verified the output.
* **Time & Space Complexity:** Not applicable.
* **Sample Input/Output:** Queries and outputs are given in the respective program files.
* **Screenshots:** All corresponding output screenshots are available inside the Output folder.

## Learning Outcomes
Learned to use aggregate functions such as COUNT, SUM, MIN, MAX, and AVG to summarize employee data. Also practiced using GROUP BY to group records and HAVING to filter grouped results based on aggregate conditions.
