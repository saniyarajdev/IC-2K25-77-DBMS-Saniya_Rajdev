# Lab_03 - DBMS ASSIGNMENT_02

## Program Specifications

* **Program_01**
  * **Problem Statement:** Write a query to display the names (first_name, last_name) using alias name "First Name", "Last Name".

* **Program_02**
  * **Problem Statement:** Write a query to get unique department ID from employee table.

* **Program_03**
  * **Problem Statement:** Write a query to get all employee details from the employee table order by first name, descending.

* **Program_04**
  * **Problem Statement:** Write a query to get the names (first_name, last_name), salary, PF of all the employees (PF is calculated as 15% of salary).

* **Program_05**
  * **Problem Statement:** Write a query to get the employee ID, names (first_name, last_name), salary in ascending order of salary.

* **Program_06**
  * **Problem Statement:** Write a query to get the total salaries payable to employees.

* **Program_07**
  * **Problem Statement:** Write a query to get the maximum and minimum salary from employees table.

* **Program_08**
  * **Problem Statement:** Write a query to get the average salary and number of employees in the employees table.

* **Program_09**
  * **Problem Statement:** Write a query to get the number of employees working with the company.

* **Program_10**
  * **Problem Statement:** Write a query to get the number of jobs available in the employees table.

## Lab Overview

* **Approach:** Wrote the required SQL queries, executed them in MySQL Workbench, and verified the output.
* **Time & Space Complexity:** Not applicable.
* **Sample Input/Output:** Queries and outputs are given in the respective program files.
* **Screenshots:** All corresponding output screenshots are available inside the Output folder.
  
## Learning Outcomes
Learned how to pull specific columns out of a table using SELECT queries. Also practiced basic operations like sorting names alphabetically using ORDER BY, changing names to capital letters using UPPER, and calculating mathematical totals like SUM and AVG.
